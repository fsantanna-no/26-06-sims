# State to save (main loop, between actions: peers idle)

- holders: HOLD, CNT, ACTIVE; merges: HEAD, SEEN, MGONLY
- schedule: HEAP, SEQ, TIMER, PEND, TICK, SCHED
- authors: KEYOF, PLACE, NAUTH, AUTH (keys stay in G.BASE)
- stats: STATS, POST, FF, MG, BORN, VIS, NC, NB, NA, PT, RX,
  TX, TMAX, RCN, CH, CLA, PCL, MXP, MXF, MXV, R
- loop: last action `a`, elapsed wall secs
- recomputed on resume (same seed): EVENTS, topology, CLASS,
  PHASE, DOWN (own RNG)

# Random sequence

- `math.random` state cannot be saved (Lua 5.4)
- reseed `math.randomseed(G.SEED, a)` every CKPT_N actions,
  in every run: a resumed run equals an uninterrupted one
- runs from now on differ from older runs after action CKPT_N

# Checkpoint

- config: `CKPT_N = env('CKPT_N', 5000)` (0: off)
- at `a % CKPT_N == 0`, after sweep/keep:
    - reseed, then dump the state to `state.lua` (Lua source,
      floats `%.17g`, number lists packed as strings)
    - `cp -a` G.BASE (with `state.lua`) to `<BASE>.ckpt.new`,
      then replace `<BASE>.ckpt` (one checkpoint kept)
    - print `== <a> ckpt <secs>s <size>`
- cost at 20k: ~7.4 GB copy, ~1 min per ~9 h of run; disk 2x

# Resume

- env `RESUME=1`: skip wipe and setup; `cp -a <BASE>.ckpt`
  to G.BASE; load `state.lua`; `t0 = now() - elapsed`
- loop from `a + 1`; print `== resume at <a>`
- runner script appends to the log (`>>`)
- KEEP/EV copies already done are not redone

# Memory

- `EV_N = env('EV_N', 10000)`; 0: no ev.sh during the run
  (run ev.sh on the kept copies after)
- start the run from the user's terminal (not reaped)
