# Mapping (`lemmy/lemmy-simple.lua`, lineage of `gh-simple.lua`)

- easiest to hardest
- init: one chain per community, at its creation date
    - gated: `--dictator` = first moderator
- post: post/comment -> signed post by actor id
    - payload: post = title + body (or url), comment = body
    - parent kept in the TSV only (as GitHub)
- sweep: every WINDOW; admin purge -> revoke + sweep
- get payload/metadata: checks only
- list order/dag/revokes/begs: metrics
- reps: gated beg/afford decisions, as GitHub
- revoke: modlog removal (`removed=true`) by the moderator
  key, `--why=<reason>`, amount 1000 + likes received
    - author self-delete -> free self-revoke
    - `technology`: 90% of removals by an AutoMod bot
- unrevoke: modlog restore (`removed=false`), `--file=<body>`
- like/dislike: vote -> 1000 by the voter; data gap (Data)
- daemon: one per instance, via `peers.sh`
- clone: instance first federates the community
    - date not public; proxy = first post by its users
- sync: star per community, not mesh
    - B -> home A -> other subscribers
    - defederation = a star link off from its date
- discard: no clean counterpart
    - ban: home refuses a post B kept -> B discards
    - refederation hard fork -> discard and repost
    - else won't do
- ban -> the member stops posting
- blocklist import = a peer refusing a whole set of members

# What it adds over current corpora

- per-user votes with named voters (GitHub had them, SE not)
- removals with reason AND the moderator identity
- INSTANCES: the same community as seen by N instances
