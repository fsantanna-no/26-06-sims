# Goal

- replay a Lemmy community over Freechains
- first corpus with REAL PEERS: instances holding the same
  community with different moderation and visibility
- feeds `260924-topology.md`: real sync cadence and real
  partitions (defederation dates) instead of synthetic ones
- paper side (relevance, consensus, moderation, votes, academic
  work, 5.3 text): `/x/papers/2606-vcs/.claude/plans/260930-lemmy.md`

# Data

- posts, comments, communities, modlog: public REST API per
  instance, historical (`/api/v3/...`, `/api/v3/modlog`)
    - modlog has reason, moderator, removed post
    - removed body only for text posts (link posts: url)
    - cap: 100 pages x 50 = 5000 entries per filter
    - fetch per `community_id` and per `type_`
    - large communities hit the cap: `technology@lemmy.world`
      page 100 = 2023-07-26, created 2023-06-11
    - pick a mid-size pilot to get full history
- per-user votes: NOT in the public API
    - run a federated instance subscribed to the target
      communities (prospective only)
    - or ask instance operators
    - or Kbin/Mbin public voter lists (historical, partial)
- defederation timeline: public blocklists + fediseer history
    - exact dates: instance announcements (manual)
    - lemmyverse `data.lemmyverse.net/data/instance.full.json`:
      per-instance `blocked` list, current only
        - 496 instances, 1392 block edges, 472 Lemmy->Lemmy
        - Wayback: 13 snapshots 2023-10 to 2026-03 -> coarse
          block dates
    - `/api/v3/federated_instances`: current blocklist only,
      no block dates; Wayback for lemmy.ml: 2023-09 to 2025-04
    - `fediseer.com/api/v1/reports`: censure/hesitation
      ADDED/DELETED, 15,642 events, 2023-09-11 to 2026-10-03
        - only 216 Lemmy->Lemmy, from 19 instances
        - bulk import 2023-09: earlier blocks undated
        - lemmy.world: 200 of 203 censures = real blocks
    - Lemmy 1.0 logs instance blocks in the modlog, but no
      crawled instance runs 1.0 (488 of 496 on 0.19)
    - Fedivertex (Kaggle, CC BY 4.0): Lemmy federation graphs,
      14 weekly snapshots; blocks not checked
- removed posts stay in the database (`removed=true`), often
  retained by remote instances -> revoke WITH payload, as GitHub
  minimized comments
- cache raw JSON under `data/lemmy/<instance>-<community>/`
- add to `fetch.sh`

# Mapping (`lemmy/lemmy-simple.lua`, lineage of `gh-simple.lua`)

- one chain per community
- post/comment -> signed post by actor id
- Like/Dislike -> like/dislike 1000 by the voter
- modlog removal -> revoke by the moderator key, WITH reason
  (spam, rule, off-topic)
- ban -> the member stops posting
- instance = peer; defederation = partition schedule
- blocklist import = a peer refusing a whole set of members

# What it adds over current corpora

- per-user votes with named voters (GitHub had them, SE not)
- removals with reason AND the moderator identity
- INSTANCES: the same community as seen by N instances

# Runs

- single-peer replay
    - GitHub-like size (~50k events), same driver shape and
      metrics as `260917-github.md`
    - expect dislike share and revoke rate between GitHub
      (9%, 5%) and wiki
- P2P replay
    - instances = peers, federation delays = sync cadence
    - defederation dates = partitions
    - depends on `peers.sh` from `260924-topology.md`
- pilot: one mid-size community on two instances that later
  defederated; posts + modlog historical, votes prospective
  if needed
