# Goal

- first corpus with LIKE and REVOKE on the same events
    - reactions: per-user, timestamped 👍/👎 (real votes;
      SE/Reddit only have aggregates or anonymized)
    - minimized comments: hidden with a public reason
      (spam | abuse | off-topic | outdated | resolved |
      duplicate), payload still readable = revoke with payload
- real logins as identities (no IPs, no shared anon)
- git-native corpus: nice for the paper's story

# Data (GraphQL, `gh api graphql`)

- repository.issues (+ pullRequests?): title/body/author/
  createdAt; comments: body/author/createdAt/isMinimized/
  minimizedReason; reactions: content/user/createdAt
- deleted comments are gone (like SE); minimized = the
  visible revoke; edit history available (userContentEdits)
- the minimizer is NOT exposed -> revoke signed by a repo
  maintainer key (dictator role), like the wiki gated mode
- rate: 5,000 points/h; ~1 point per 100 nodes -> a 50k
  comment repo in a few hours; cache raw JSON under
  `sims/data/github/<owner>-<repo>/`
- add to `sims/fetch.sh` (needs `gh auth`)

# Mapping (gh-simple.lua)

- issue / comment -> signed post (payload = body; reference
  to parent issue inside the payload)
- reaction 👍 / 👎 -> like / dislike 1000 action <cid> by the
  reacting user's key (other reactions ignored)
- minimized comment -> revoke (outweigh its likes) by the
  maintainer key at ... when? minimize time is NOT exposed:
  apply at the comment's last-edit time or at fetch time
  (end of replay); record which
- GATED mode as wiki: dictator = maintainer; begs + welcomes;
  resurrection split by minimizedReason (spam/abuse = vandal,
  off-topic/outdated = innocent)
- ts clamp as before; env: REPO/LIMIT/WINDOW/SWEEP/GATED

# Metrics

- as before: ev avg, loose/window, sweep, packed floor
- like/dislike per post; dislike share vs SE (7-8%)
- revoke rate by reason; reactions on later-minimized comments
  (were they disliked BEFORE being hidden? = community
  signal precedes moderation)
- resurrection precision with a REAL reason label
